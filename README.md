# ChatProtect
ChatProtect - NEO Organization - это чат бот для тегерамм который модерирует сообщение на наличие запрещёных слов, с тонкой настройкой, а также имеет систему "шуток". Проект распространяется по лицензии GPL v3.

Фнкционал бота:
При появлении нового сообщения бот получает весь текст сообщения, затем есть2 этапа проверки
1 Этап - текст переходит в нижний регистр, базовая чистка символов - если найдено совпадение по базе - удаляем сообщение и добавляем нарушение (если пользователь модератор - просто удаляем сообщение), если проверка прошла то второй этап:

2 Этап - более агресивная чистка сооьщения (замена символов например: @ на а, 0 на о т.д) - найдено нарушение? удаляем сообщение добавляем нарушение.

Если сообщение было изменено то происходит повторная проверка в теже 2 этапа, найдено нарушение? - удаляем сообщение, добавляем 2 нарушения.

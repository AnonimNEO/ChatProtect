# ChatProtect
ChatProtect - NEO Organization - это чат бот для тегерамм который модерирует сообщение на наличие запрещёных слов, с тонкой настройкой, а также имеет систему "шуток". Проект распространяется по лицензии GPL v3.

> [!WARNING]
> Данный проект находится в Alpha!
> На данный момент код запускается, работает не стабильно!

## Фнкционал бота:

При появлении нового сообщения бот получает весь текст сообщения, затем есть 3 этапа проверки

0 Этап - проверка напрямую, найдено запрещёное слово? - добавляем 1 нарушение.

1 Этап - убираем все символы (кроме алфавита и цифр), найдено запрещёное слово? - добавляем 2 нарушения.

2 Этап - убираем не все символы, а затем замена символов (например @ на а, а 0 на о), найдено запрещёное слово? - добавляем 3 нарушения.

Если сообщение было изменено то происходит повторная проверка в теже 3 этапа, найдено нарушение? - удаляем сообщение, добавляем x2 нарушения (в зависимости от этапа).
